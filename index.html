普通网络传输 · SDK 示例

这些层相互配合。100GbE 不等于 TCP，也不代表应用一定能跑满 100 Gb/s。

远程内存传输 · RoCE v2

RoCE v2 不经过 TCP。UDP 在这里用于封装；可靠性由所选 RDMA 传输服务负责。

搬运数据 ≠ 共享缓存

DMA / RDMA 解决“怎样搬过去”。缓存一致性解决“多个处理器缓存的同一地址，如何保持可见的一致状态”。有 RDMA 不代表 CPU 与 GPU 自动拥有一致性内存。

Scale-up ≠ CPU 专用连接

在这里，NVLink / NVSwitch 把一组 GPU 组成紧密互联域。NVL72 将这个域扩展到整个机柜；CPU 的本地 C2C 连接是另一条需要单独分析的路径。

Scale-out ≠ NVL72

多个服务器或机柜通过 InfiniBand 或 Ethernet / RoCE 网络扩展。NVL72 是系统配置名称，NVLink 是互连技术，NCCL 是通信库。
